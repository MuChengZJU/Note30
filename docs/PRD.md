# 产品需求文档 (PRD) - Note30

## 1. 简介

Note30 是一款极简的安卓应用，旨在通过每 30 分钟一次的周期性提醒，帮助用户对抗“时间黑洞”，并记录工作与情绪，以便后续复盘分析。应用的核心设计理念是“快速记录，后续分析”，保持 App 本身的轻量与专注，同时通过强大的导出功能赋能用户进行深度的数据挖掘。

## 2. 核心目标

- **干预低效状态**：通过周期性提醒，帮助用户从“摸鱼”、“时间黑洞”等无意识的状态中脱离出来，审视刚刚过去的时间。
- **记录与复盘**：结构化地记录用户的活动、效率和情绪，并通过 Markdown 导出功能，为后续的工作总结、个人复盘和 AI 分析提供高质量的数据源。
- **平衡专注与打扰**：在提供有效干预的同时，尊重用户需要高度专注或休息的时刻，提供“免打扰”的选项，避免成为一个令人烦躁的工具。

## 3. 功能详述

### 3.1 核心循环：提醒与记录

1.  **计时器**：App 在后台以 30 分钟为周期运行一个计时器。
2.  **首次提醒**：计时结束时，发送一个温和的系统通知（声音/震动+顶部弹窗）。用户可以点击通知进入记录界面，也可以忽略。
3.  **二次提醒**：如果用户在 3 分钟内未对首次提醒做出响应，App 会发送第二次、也是最后一次通知。
4.  **记录**：用户在记录界面输入内容后，计时器自动开始下一个 30 分钟的周期。
5.  **跳过**：如果二次提醒后用户仍未记录，则该时间段的记录作罢，App 自动开始下一个周期。

### 3.2 记录界面

记录界面追求极简与高效，由以下三部分组成：

1.  **主文本输入框**：支持用户自由输入文本，为语音输入优化。
2.  **效率评级**：1-5 的数字评级，供用户快速选择。
3.  **情绪标签 (可选)**：提供一组预设的词语（如：平静, 高效, 疲惫, 分心）作为快捷标签。此项为可选项，用户可以不选择。

### 3.3 历史回顾与导出

1.  **界面布局**：
    - App 主界面采用底部双 Tab 导航，分别为**记录** (默认页) 和 **历史**。
    - **历史**页面提供两种视图模式，可通过右上角图标切换：
        - **时间线视图**：以每日为卡片，按时间倒序展示记录流。
        - **日期列表视图**：更紧凑的列表，方便快速跳转到特定日期。

2.  **导出功能**：
    - **触发方式**：
        - **批量导出**：在历史页面的右上角，提供批量导出功能，允许用户选择日期范围。
        - **单日导出**：在时间线视图的每日卡片上，或进入某一天的详情页后，可以导出当日记录。
    - **导出动作**：提供“复制到剪贴板”和“通过系统分享”两个选项。
    - **导出格式**：所有记录将被格式化为结构化的 Markdown 文本。
        - **情绪**字段为可选，仅在用户选择时出现。
        
        ```markdown
        # 2025-09-11

        ## 09:00 - 09:30
        - 效率: 4
        - 情绪: 高效
        - 记录: 完成了项目 A 的需求文档初稿。

        ## 09:30 - 10:00
        - 效率: 3
        - 记录: 参加了团队的每日站会，讨论了一些问题。
        ```

### 3.4 特殊场景处理：暂停与恢复

为处理午睡、会议等需要长时间免打扰的场景，App 提供“暂停后总结”机制：

1.  **手动暂停**：用户可在主界面手动点击“暂停”按钮，之后 App 将停止所有计时和提醒。
2.  **恢复并总结**：当用户返回 App 并点击“恢复”时，App 会弹出一个总结窗口，显示暂停的总时长（例如 “1 小时 30 分钟”），并要求用户对整个时段进行**一次性**的总结记录。
3.  **记录合并**：这次总结性的记录将被保存，并覆盖整个暂停的时间段。

## 4. 非功能性需求

- **性能**：App 后台服务应轻量，电量消耗极低。
- **数据存储**：所有用户数据均在本地存储，无需联网。
- **平台**：安卓 (Android)。
