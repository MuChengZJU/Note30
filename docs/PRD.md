# 产品需求文档 (PRD) - 灵感菇

## 1. 简介

灵感菇是一款主打 AI 驱动的极简日记应用。它将传统日记的“记录-分类-回顾”模式，彻底革新为“记录-AI分析-洞察”的全新流程。应用摒弃了所有手动的分类、打分和标签系统，只提供一个纯粹的文本输入框，旨在最大程度地降低用户的记录门槛。

用户只需随手记录，灵感菇便会利用用户自行配置的第三方大语言模型（LLM）API，在后台对文本进行深度分析，自动识别情绪、提取关键词、生成摘要，并将这些结构化的信息与原始文本一并保存。

## 2. 核心目标

- **无压力记录**: 提供极致简洁的界面，让用户可以随时随地、毫无负担地捕捉脑海中闪现的任何想法、感受或事件。
- **AI 深度洞察**: 将用户的零散记录转化为结构化的、有意义的数据洞察。AI 自动完成情绪分析、主题分类和内容总结，帮助用户发现自己思维和情绪的模式。
- **隐私与自主权**: 用户的日记数据和 AI 服务配置（API Key）完全存储在本地，不上传任何服务器。用户对自己数据的拥有绝对的控制权。
- **高度个性化**: 用户可以连接任何兼容 OpenAI API 规范的 LLM 服务，自由选择模型，甚至在未来可以自定义分析维度（通过调整 Prompt），打造完全属于自己的智能日记。

## 3. 功能详述

### 3.1 核心循环：记录与分析

1.  **输入**: 用户在主界面自由输入文本。
2.  **保存**: 用户点击保存后，文本和当前时间戳立即存入本地数据库。
3.  **后台分析**: App 在后台调用用户在设置中配置的 LLM API，将文本发送进行分析。
4.  **结果回填**: API 返回分析结果（一个结构化的 JSON 对象）后，App 将其更新到对应记录的 `ai_analysis` 字段中。
5.  **洞察呈现**: 在历史记录中，AI 的分析结果（如情绪、摘要、标签）将与原文一同展示，提供更丰富的回顾视角。

### 3.2 记录界面

- 界面只有一个核心元素：一个全屏或近全屏的、鼓励沉浸式输入的文本框。
- 界面上仅有一个“保存”按钮。

### 3.3 历史回顾与导出

1.  **界面布局**:
    - App 主界面采用底部双 Tab 导航，分别为**记录** (默认页) 和 **历史**。
    - **历史**页面以时间线视图展示所有记录。每条记录卡片上除了显示原文，还会以标签、摘要等形式展示 AI 的分析结果。

2.  **导出功能**:
    - **触发方式**: 在历史页面的右上角，提供批量导出功能，允许用户选择日期范围。
    - **导出动作**: 提供“复制到剪贴板”和“通过系统分享”两个选项。
    - **导出格式**: 所有记录将被格式化为结构化的 Markdown 文本，其中包含 AI 的分析结果。
        
        ```markdown
        # 2025-09-15

        ## 10:30
        - 原文: 完成了项目 A 的需求文档初稿，感觉很有成就感，但是对下午的会议有点焦虑。
        - AI 分析:
          - 情绪: 积极，伴随轻微焦虑
          - 关键词: 项目A, 文档, 成就感, 会议, 焦虑
          - 摘要: 用户完成了工作任务并感到满意，但对即将到来的会议表现出担忧。
          - 分类: 工作

        ## 11:00
        - 原文: 团队的每日站会，讨论了一些问题，进行得很顺利。
        - AI 分析:
          - 情绪: 平静
          - 关键词: 站会, 团队, 讨论
          - 摘要: 参加了例行的团队会议。
          - 分类: 工作
        ```

### 3.4 AI 配置界面

为了连接 AI 服务，应用需要在设置中提供一个专门的配置界面。

1.  **API 地址 (URL)**: 文本输入框，允许用户填入任何兼容 OpenAI 的 API 端点地址。
2.  **API 密钥 (Key)**: 密码输入框，用于安全地输入和存储用户的 API 密钥。
3.  **模型选择**:
    - 提供一个“获取模型列表”的按钮。
    - 点击后，应用会调用该 API 的 `/v1/models` 端点，获取可用的模型列表。
    - 将获取到的模型展示在一个下拉菜单中，供用户选择。
4.  **保存与测试**: 提供保存和测试连接有效性的按钮。

## 4. 非功能性需求

- **性能**: App 启动和响应应足够迅速，UI 流畅。
- **数据存储**: 所有用户数据，包括 API 配置，均使用安卓标准方式（如 Room, SharedPreferences/DataStore）在本地加密存储。
- **平台**: 安卓 (Android)。
- **网络**: 应用在进行 AI 分析时需要网络连接。应妥善处理网络异常情况（如分析失败后可重试）。
